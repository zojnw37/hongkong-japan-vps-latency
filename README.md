## 延迟：三档区间，和口径差异的来源

物理距离决定延迟下限，这一项花钱也很难绕过。

| 节点 | 到中国大陆延迟（资料口径） | 差异来源 |
| --- | --- | --- |
| 香港 | 10–50ms；珠三角可低至 10–40ms，北方通常 30–50ms，另有商家口径为 40–70ms | 回国线路是否优化，测点在南方还是北方 |
| 日本 | 30–120ms；优化线路 40–80ms，普通线路晚高峰更高，大阪软银约 60–90ms | 机房在东京还是大阪，回程走 CN2 GIA、软银还是 CMI |
| 美国西海岸 | 120–180ms，普遍在 150ms 以上 | 线路优化能压丢包，改不了距离 |

香港那 10–50ms 和 40–70ms 的差距，来自不同商家在南方和北方、电信和联通移动上的测点差异，不是谁在造假。日本 30–90ms 与 60–120ms 同理：东京 Equinix 机房走多线 BGP 加 CN2 GIA，和一台走普通线路的大阪机器，本来就不是一个东西。

顺带排除一个选项：新加坡到国内约 60–90ms，做纯东南亚业务可以纳入考虑，以国内用户为主的站点放过去并不划算。

规律很清楚：入门配置上香港只贵一顿饭钱，配置往上走，价差迅速拉开到三分之一以上。原因在带宽成本——同等 CPU 内存下，香港的带宽成本通常比美国高 30%–50%，商家只能把成本摊进价格或者砍带宽。所以低价位香港 VPS 常见只有 2–5M，这类机器跑文字站、配个 CDN 完全够用，指望它扛图片和视频就不现实。

日本的位置在两者之间：带宽通常比香港给得大方，但线路质量参差。有个活动机案例很能说明问题：同一家商家的 4核4G 年付套餐，香港和日本给 30Mbps，美国同价给 100Mbps。这 100Mbps 是端口带宽，国内访问快不快，还是要回到回程线路判断。

另外一个通用规律：年付普遍比月付便宜约 30%。长期项目直接年付，短期测试先月付，别为了折扣把自己锁一年。

## 线路比地区更重要：CN2 也分去程和回程

很多商家宣传页上写着 CN2，实际只优化了去程，回程照走普通骨干，晚高峰一样卡。这是买香港机器最容易踩的坑，而且从商品页看不出来。

验证方法不复杂：下单前让客服给一个测试 IP，本地跑 `mtr -r -c 100 <IP>`，看回程经过哪些节点。回程地址落在 59.43 开头的段，通常说明走的是电信 CN2；出现 202.97，那就是普通 163 骨干。电信用户尤其要查这一步，日本普通线路晚高峰的波动，多数就出在回程。

同一地区内部的线路分层，有时比地区之间的差距还大。香港侧常见的分法是三档：Premium 系列做电信双向 CN2 GIA、联通移动直连；Eyeball 系列走三网 CMI，性价比通常优于 Premium；Tier 1 是纯国际线路，没有大陆优化，只适合面向东南亚的业务。

日本侧的分法不一样：软银（bbtec.net）是日本本土主流运营商，国内电信、联通方向常见走软银回程，延迟相对稳；CN2 GIA 机房三网回程都做优化，价格最高；CMI 回程的机房移动用户体验最好。拿搬瓦工的日本机房做个量化：大阪 CN2 GIA（2核2G/40G/500GB/1.5Gbps）$49.99/月、$499.99/年，东京同配置（1.2Gbps）$89.99/月、$899.99/年，大阪比东京便宜约 45%。

也就是说，东京和大阪之间的价差，可能比香港和日本之间的价差还大。选商家时只盯着“香港还是日本”这一个维度，容易在错误的机房里多付一倍钱。

## IP 属性：日本节点大多是广播 IP，原生 IP 往往要加钱

这一条在前排的对比文章里基本没人提，但它直接决定你买的机器能不能跑日本流媒体、能不能用来做账号业务。

日本机房分配给 VPS 的 IP，很多是广播 IP，不是原生 IP。查归属地可能显示别的地区，对流媒体解锁和风控敏感的业务影响很大。有服务商在官方说明里写得很直白：香港和日本是广播 IP，不承诺 100% 能访问有特定要求的网站。

具体到加钱这件事，恒创科技的口径是：日本节点默认开通常规 BGP IP，不是原生 IP；需要原生 IP 要联系客服额外付费，200 元/月/个。香港和美国节点默认就是当地原生 IP。日本一个原生 IP 的月费，接近一台入门 VPS 的年付价，这笔钱在做预算时不能漏。

还要区分两类产品。日本 ISP 住宅 IP 和原生 IP 不是一回事：做 TikTok、社媒账号运营选住宅 ISP，做独立站或流媒体访问选原生 IP。丽萨主机的定价可以做参照——日本原生 IP VPS 不限流量版 ¥598/月，ISP 住宅 IP 从 ¥169/月的固定流量版本起步；退款政策也不同，原生 IP 支持 48 小时无条件退款，住宅 IP 只退网站余额。

如果你的业务对 IP 归属不敏感，广播 IP 完全没影响，不用为这一项多付钱。

## 常见问题

**日本 VPS 需要备案吗？**
不需要。境外服务器不受国内备案约束，开通后直接部署。内容仍要符合机房所在地法规，违规内容同样会被处理。

**2M 带宽够不够用？**
纯文字博客和中小型站点够用，CN2 GIA 线路的实际体验不输带宽更高的普通线路。图片视频多的站点建议 5M 以上，或者直接上大带宽版本。

**晚高峰卡怎么办？**
先查回程。回程走普通骨干的，换机房或换商家比加钱升配更有效。移动用户优先看 CMI 回程，联通用户看软银，电信用户看 CN2 GIA。

**买错了能不能退？**
看你买的是哪家、哪个套餐。常规套餐通常有几天无理由期，活动机和特价机常常被排除在外。下单前把退款条款截个图。
